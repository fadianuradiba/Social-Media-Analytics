# Social Media Analytics

## Project Overview

This project focuses on analyzing social media user behaviour and platform performance using Google BigQuery, Python, and social media user behavior data. The analysis explores user demographics, engagement patterns, platform performance, content preferences, and social commerce activities to identify business insights and support data-driven decision-making.

## Business Objectives

- Understand user demographics and social media activity patterns.
- Analyze user engagement and behavioural trends.
- Evaluate performance across different social media platforms.
- Identify content types that generate higher user engagement.
- Analyze social commerce performance and purchasing behaviour.
- Provide actionable recommendations to improve engagement and monetization strategies.

## Dashboard Pages

1. **Overview** — presents key metrics and an overall summary of social media user activity and performance.
2. **User Segmentation** — explores user demographics and behavioural segments.
3. **User Behavior** — analyzes user activity patterns, usage intensity, and device preferences.
4. **Platform Analysis** — compares social media platforms based on engagement and performance.
5. **Content & Engagement** — examines content preferences and engagement patterns across different content types.
6. **Social Commerce** — analyzes purchasing behaviour, conversion, and revenue performance across platforms.
